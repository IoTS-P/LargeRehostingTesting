# StringBaseFinder

## Category

- IoT Firmware

## Description

Finds the base address of firmware through string address matching.

### Configuration File

Configuration file class: `org.iotsplab.akiba.process.StringBaseFinderConfig`

```json
{ 
  "subtractionMapThreshold": 0.2,   // Minimum frequency threshold for differences 
  "decompileThreadNumber": 8,       // Number of decompilation threads 
  "scalarClusterEpsilon": 262144,   // Clustering 𝛆 value, default is 0x40000 
  "pythonPath": "/bin/python3"      // Python path, default is /bin/python3 
}
```

### Database Columns

- 🟢 `base_address INTEGER`: The obtained base address value.

## Supplementary Explanation

The tasks of this module can be divided into four steps:

1. Obtain all constant values (scalars) in the firmware
2. One-dimensionally cluster constant values based on proximity
3. Select the largest clusters to build difference mappings
4. Obtain the most probable base address

### 1. Obtain all constant values (scalars) in the firmware

To simplify binary analysis, we use the pseudo-C code generated by Ghidra for each function to extract all scalar values from each function and aggregate them into a set.

### 2. Cluster constant values

Considering that not all scalars are actual addresses, we need to cluster the scalars. Adjacent values have a high probability of being grouped together.

We use the HDBSCAN clustering algorithm to cluster scalars. The default epsilon is 0x40000 (4MiB space, which should be sufficient for most firmwares).

### 3. Select the largest clusters to build difference mappings

After obtaining clustering results, we need to select the largest clusters to build difference mappings. In some large firmwares, the number of strings and scalars can be very large, so building a complete difference mapping is very time-consuming and memory-intensive for large datasets. Therefore, for firmwares with more than 500 strings or more than 500 scalars, we will randomly select 500 strings and 500 scalars to build difference mappings (random selection will be performed multiple times to eliminate randomness as much as possible).

### 4. Obtain the most probable base address value

After obtaining the difference mappings, we can examine which difference appears most frequently through subtraction; this is the characteristic of the most probable base address.
