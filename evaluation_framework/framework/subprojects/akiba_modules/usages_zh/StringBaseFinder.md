# 基于字符串的基地址获取模块 —— StringBaseFinder

## 分类

- 物联网固件

## 描述

通过字符串地址匹配寻找固件的基地址

### 配置文件

配置文件类：`org.iotsplab.akiba.process.StringBaseFinderConfig`

```json
{
  "subtractionMapThreshold": 0.2,   // 差值出现频率最低阈值
  "decompileThreadNumber": 8,       // 反汇编线程数
  "scalarClusterEpsilon": 262144,   // 聚类 𝛆 值，默认为 0x40000
  "pythonPath": "/bin/python3"      // python 路径，默认为 /bin/python3
}
```

### 数据表列

- 🟢 `base_address INTEGER`: 获取的基地址值

## 补充解释

本模块的任务步骤可以分为四步：

1. 获取固件中的所有常量值(标量)
2. 按照临近情况一维聚类常量值
3. 选择最大的几个聚类组构建差值映射
4. 获取最可能的基地址

### 1. 获取固件中的所有常量值(标量)

为简化二进制分析，我们使用Ghidra生成的每个函数的伪C代码来提取每个函数中的所有标量值，并聚合到一个集合中。

### 2. 聚类常量值

考虑到不是所有标量都是实际地址，我们需要将标量聚类。相邻的值有很大概率会被归于同一个组。

我们使用 HDBSCAN 聚类算法对标量进行聚类，默认的 epsilon 为 0x40000（4MiB 空间，对于大多数固件应足够）。

### 3. 选择最大的几个聚类组构建差值映射

获取聚类结果后，我们需要选择最大的几个聚类组构建差值映射。在一些大固件中，字符串和标量的数量可能会非常多，因此构建完整的差值映射对于大型数据集来说非常耗时和内存占用，因此对于有超过 500 个字符串或超过 500 个标量的固件，我们会随机选择 500 个字符串和 500 个标量来构建差值映射（将随机选择多次，以尽可能地消除偶然性）。

### 4. 获取最有可能的基地址值

获取差值映射后，我们可以通过减法来查看哪个差值重复出现最多，这是最可能的基地址的特征。
