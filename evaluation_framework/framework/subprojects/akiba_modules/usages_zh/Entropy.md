# 熵计算模块 —— Entropy

## 分类

- 物联网固件
- 固件分析

## 描述

计算固件文件的香农熵（Shannon Entropy），用于评估数据的随机性和压缩性。

## 数据与模块交互

### 配置文件

本模块不需要配置文件。

### 数据表列

- 🟢 `entropy DOUBLE PRECISION`: 本模块将输出到数据库的熵值

## 补充解释

该模块的主要功能和工作原理：

1. **熵的概念**：香农熵是信息论中用于度量信息量的概念，在固件分析中可用于：
   - 检测加密或压缩的数据区域
   - 识别代码段和数据段
   - 发现潜在的恶意代码隐藏区域

2. **计算方法**：
   - 使用缓冲区（8KB）读取文件内容
   - 统计每个字节值（0-255）出现的频率
   - 根据香农熵公式计算：$H = -\Sigma p(x) \log_2(p(x))$
   - 熵值范围：0（完全有序）到 8（完全随机，对于字节而言）

3. **性能优化**：
   - 使用缓冲流提高读取效率
   - 使用 IntArray 存储字节频率计数
   - 支持大文件处理，不会一次性加载整个文件到内存

4. **结果解读**：
   - 低熵值（接近 0）：数据高度有序，可能是代码段或未初始化数据
   - 中熵值：普通数据
   - 高熵值（接近 8）：数据高度随机，可能是加密或压缩数据

## 备注

1. **输入文件**：使用 `usingFile` 作为输入文件进行分析
2. **失败处理**：如果任务被取消，模块将标记为失败状态（@FailOnCancelled）
3. **应用场景**：常用于固件安全分析的预处理阶段，帮助定位需要重点关注的区域
