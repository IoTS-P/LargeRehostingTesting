# 函数暴力搜索模块 —— FunctionFinder

## 分类

- 物联网固件

## 描述

尝试查找 Ghidra 没有找到的函数，且补充定义。

## 数据与模块交互

### 模块依赖

- 🔴 (可选) `org.iotsplab.akiba.process.ARMBaseFinder`: ARM Cortex 固件使用，用于跳过文件开头的中断向量表。

## 补充解释

本模块中包含数个定义函数的方法：

1. 暴力搜索所有的直接函数调用指令机器码（因为 Ghidra 使用递归反汇编算法而非线性反汇编算法，所以只有通过搜索机器码才能找到遗漏的函数调用指令），随后让 Ghidra 自动分析。
2. 函数与函数之间可能存在一些未定义字节，在实际情况下它们大概率是函数。因此我们可以尝试反汇编函数之间的未定义字节以补充定义函数。
3. 在 ARM Cortex 系列固件中，一些未实现的中断函数可能会以死循环填充。有时这些未实现函数会占据中断向量表中的大部分函数。我们可以通过搜索 `\xFE\xE7` 来找到并定义它们，这样可以提升 `ARMBaseFinder` 模块的准确度。
4. 将所有不属于任何函数的悬挂汇编代码段定义为未定义字节，它们大部分实际上都应是数据。
